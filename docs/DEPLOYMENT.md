# AWS EC2 Docker Deployment

## Objective

Deploy a Dockerized application on AWS EC2.

## Environment

- AWS EC2 Ubuntu
- Docker
- Nginx

## Deployment Steps

1. Launch EC2 Instance
2. Configure Security Groups
3. Connect via SSH
4. Install Docker
5. Build Docker Image
6. Run Container
7. Verify Deployment

## Troubleshooting

- Checked docker ps
- Checked docker logs
- Verified Security Groups
- Verified Port 80 accessibility
- Tested using curl

## Result

Successfully deployed application to AWS EC2.
